# 💪 健身月历 (Fitness Calendar)

一个简洁实用的健身训练记录日历应用，帮助你追踪和管理每日健身数据。

## ✨ 功能特性

- **📅 月历视图** - 直观的日历界面，快速查看每日训练情况
- **🏋️ 训练记录** - 支持胸肌、背部、肩部、腿部、手臂、核心、有氧等分类
- **📊 容量统计** - 自动计算训练容量（组数 × 次数 × 重量）
- **📈 趋势图表** - 可视化展示各部位训练容量变化趋势
- **💾 数据导出/导入** - 支持 JSON 格式数据备份与恢复
- **📱 移动端适配** - 响应式设计，完美支持手机浏览器

## 🚀 快速开始

### 在线使用
直接用浏览器打开 `index.html` 即可使用。

### 本地运行
```bash
# 克隆仓库
git clone <repository-url>

# 进入目录
cd fitness-calendar

# 用浏览器打开
open index.html
```

## 📖 使用说明

1. **添加训练** - 点击日期或右上角「+ 添加」按钮
2. **选择部位** - 选择训练部位（胸肌、背部、肩部等）
3. **填写信息** - 输入动作名称、组数、次数、重量
4. **查看记录** - 点击日期查看当日训练详情
5. **调整数据** - 可直接调整组数、次数、重量
6. **查看趋势** - 切换到「容量」标签查看训练趋势图

## 🎯 训练部位

| 图标 | 部位 | 示例动作 |
|:---:|:---:|:---|
| ❤️ | 胸肌 | 卧推、上斜卧推、哑铃飞鸟 |
| 🛡️ | 背部 | 引体向上、杠铃划船、硬拉 |
| 💪 | 肩部 | 哑铃推举、侧平举、面拉 |
| 🦵 | 腿部 | 深蹲、腿举、弓步蹲 |
| 💪 | 手臂 | 哑铃弯举、绳索下压 |
| 🎯 | 核心 | 卷腹、平板支撑、健腹轮 |
| 🏃 | 有氧 | 跑步、椭圆机、游泳 |

## 💾 数据存储

- 数据自动保存在浏览器本地存储（LocalStorage）
- 支持导出 JSON 文件备份
- 支持导入已备份的数据
