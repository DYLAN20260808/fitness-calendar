# 💪 健身月历 (Fitness Calendar)

一个简洁实用的健身训练记录日历应用，帮助你追踪和管理每日健身数据。

## ✨ 功能特性

- **📅 月历视图** - 直观的日历界面，快速查看每日训练情况
- **🏋️ 训练记录** - 支持胸肌、背部、肩部、腿部、手臂、核心、有氧等分类
- **📊 容量统计** - 自动计算训练容量（组数 × 次数 × 重量）
- **📈 趋势图表** - 可视化展示各部位训练容量变化趋势
- **💾 数据导出/导入** - 支持 JSON 格式数据备份与恢复
- **📱 移动端适配** - 响应式设计，完美支持手机浏览器

## 📖 使用说明

1. **添加训练** - 打开页面或点击「+ 添加训练」、记录页「+ 添加」时，如果当天没有记录，会根据最近一次胸部或背部训练交替选择部位，再参考该部位最近一个同类日期的动作：周六、周日相互参考，周一至周五相互参考。没有该部位的同类日期记录时可手动添加；已有记录时保留原有添加方式。清空当天记录后重新打开页面，也会再次尝试自动生成。
2. **选择部位** - 选择训练部位（胸肌、背部、肩部等）
3. **填写信息** - 输入动作名称；新动作的组数默认为 0，可再调整组数、次数和重量
4. **查看记录** - 点击日期查看当日训练详情；历史日期的记录页使用纯黑色背景。
5. **调整数据** - 可直接调整组数、次数、重量；长按减号可将对应数值设为 1。点击动作后，它会排在最左侧、秒表归零；刷新页面时恢复选中或新添加的动作
   非「随便」动作的重量或次数增加时，组数自动设为 1；减少时，所有动作的组数保持不变。
   秒表达到提醒时间时，秒表和训练时长方块会变红；秒表重置后恢复原色。
   打开或刷新页面时，如果当天已有训练记录，会自动执行一次训练时长刷新。缺少开始时间的旧记录需要先设置开始时间，才能计算有效时长。
   记录页点击「清空」并确认，可删除当前日期的全部训练记录和计时数据；历史日期须先解锁。
6. **查看趋势** - 切换到「容量」标签查看训练趋势图
7. **批量重命名** - 在「统计」页选择部位和动作，点击数据下方的「重命名」，输入新名称并确认，即可修改该部位所有日期的同名记录，保留组数、次数、重量等数据。新名称不能与同一部位的历史记录、自定义名称或预设名称重复；统计页双击改名也会校验重名。保持原名不作修改，不同部位可使用相同名称。
